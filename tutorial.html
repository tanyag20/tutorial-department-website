Subject: Data Structures & Algorithms

Welcome to the dedicated academic tutorial portal. Below is a quick illustration sample for a fundamental concept code block implementation.

Example Code Snippet (C++)

#include <iostream>
using namespace std;

int binarySearch(int arr[], int l, int r, int x) {
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (arr[m] == x) return m;
        if (arr[m] < x) l = m + 1;
        else r = m - 1;
    }
    return -1;
}
